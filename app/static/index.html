How an answer is made

  1. Hybrid search over page-sized chunks: meaning (embeddings) plus exact terms (BM25).
  2. Reranking with a cross-encoder. If nothing is relevant enough, the bot declines without calling the LLM.
  3. Claude answers from the top passages only, as structured output with citations.
  4. Checks in code: citations must point to retrieved passages, and every number must appear in a cited source.
